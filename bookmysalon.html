<What is BookMySalon? />

BookMySalon is a comprehensive, full-stack web application designed to revolutionize the salon booking experience. It serves as a bridge between customers seeking premium grooming services and salon owners looking to streamline their business operations.

The platform provides an intuitive interface for customers to discover salons, explore services, and book appointments online. For salon owners, it offers a powerful management dashboard to handle bookings, staff, services, expenses, and gallery—all in one place.

What sets BookMySalon apart is its integration of AI-powered face detection technology that provides personalized hairstyle recommendations, making it not just a booking system, but an intelligent grooming consultant.

<Why I Built This? />

The Problem

Traditional salon booking methods involve phone calls, long wait times, and lack of transparency in pricing and availability. Customers often struggle to find quality salons, compare services, and book appointments conveniently. Salon owners, on the other hand, face challenges in managing bookings, tracking expenses, and maintaining customer relationships.

The Solution

BookMySalon addresses these pain points by providing:

  • ✅ A centralized platform for discovering and booking salons
  • ✅ Transparent pricing and service information
  • ✅ AI-powered personalized recommendations
  • ✅ Comprehensive business management tools for salon owners
  • ✅ Real-time booking management and notifications

Academic Purpose

This project was developed as my B.Tech Final Year Project (2026) to demonstrate proficiency in full-stack web development, database management, API design, and integration of modern technologies like AI and responsive design. It showcases end-to-end development skills from requirement analysis to deployment.

<How to Use? />

For Customers (Users)

  1. Browse Salons: Visit the homepage and explore featured salons or search by location
  2. View Details: Click on any salon to see services, barbers, pricing, and gallery
  3. Register/Login: Create an account or login to book appointments
  4. Book Appointment: Select a service, choose date and time, and confirm booking
  5. AI Consultant: Use the AI feature to get personalized hairstyle recommendations
  6. Manage Bookings: View, track, and cancel bookings from "My Bookings" page

For Salon Owners (Staff)

  1. Register as Staff: Sign up with salon_staff role
  2. Create Salon: Add your salon with details, location, and cover image
  3. Add Services: Create service menu with pricing and duration
  4. Add Barbers: Add your team members with their expertise
  5. Upload Gallery: Showcase your work with before/after images
  6. Manage Bookings: View all bookings, update status (Confirm/Complete)
  7. Track Expenses: Record and categorize business expenses

For Developers (Setup)

  1. Clone Repository: git clone https://github.com/yourusername/BookMySalon.git
  2. Install Dependencies: npm run install-all
  3. Configure Environment: Create .env files for backend and frontend
  4. Setup Database: Configure SQL Server connection in backend/.env
  5. Start Application: npm start (runs both frontend and backend)
  6. Access Application: Open http://localhost:5173 in your browser
